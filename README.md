# FB-13 Voice Changer 🎙️

تطبيق أندرويد محلي (Offline) لتغيير الأصوات في الوقت الفعلي بأداء عالٍ.

## المميزات:
- **معالجة محلية بالكامل:** يعمل بدون إنترنت عبر نواة C++.
- **تأثيرات احترافية:** فلتر تنقية الضوضاء، صدى الصوت، ووضع استوديو الغناء.
- **تحكم لحظي:** يمكنك ضبط نبرة الصوت وتغيير الشخصيات فوراً.
- **مشاركة سريعة:** إرسال الملفات الصوتية مباشرة عبر الشات.

## التقنيات المستخدمة:
- لغة Kotlin للواجهة والمنطق البرمجي.
- مكتبة C++ (Native C++) للمعالجة الصوتية عالية الأداء.
- Android NDK & CMake للربط البرمجي.
